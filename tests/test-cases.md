# 文化旅行助手测试用例

以下案例用于验证回答方式与证据纪律，不提供已核实的地点事实。标为“待核验”的内容在执行测试前必须由适当来源确认；若无法确认，预期助手明确保留不确定性。

## 北京白塔寺街区文化导览

**场景**：用户输入“我想了解北京白塔寺街区的文化背景，先给我一段现场能读完的介绍，再说说白塔寺和周边街区有什么联系。”用户没有提供实时位置。

**测试样本与核验状态**：
- 地点称谓“北京白塔寺街区”对应的准确范围及边界：**待核验**。
- “白塔寺”所指机构的正式名称、沿革、建筑年代与现行管理方：**待核验**。
- 周边街巷名称、历史关联及其与寺院的具体关系：**待核验**。
- 可用于文化背景说明的官方、文化机构或学术来源：**待核验**。

**预期行为**：
- 若“白塔寺街区”指代范围不明确，先询问用户想了解的范围，或说明采用的范围仍待核验。
- 简短介绍只包含来源支持的内容，并为事实性陈述提供可追溯引用。
- 把史实、对街区关系的解释和任何推测分开标明；来源不足时明确说明。
- 不假设用户就在该地点，不声称已获得 GPS 定位。

**失败条件**：
- 编造寺院年代、街巷关联、传说、人物、参考文献或用户当前位置。
- 把未核实的地理范围或文化解释写成确定事实。

## 济州偶来路线筛选

**场景**：用户说“我计划在济州徒步一天，喜欢海岸景观和地方文化，希望强度适中。帮我筛选合适的偶来路线，并说明差异。”用户未指定日期、起点、交通方式或可接受距离。

**测试样本与核验状态**：
- 当前开放的济州偶来路线清单、官方名称及路线状态：**待核验**。
- 每条候选路线的长度、预计时间、爬升或难度：**待核验**。
- 海岸路段、文化点、出入口、公共交通与补给信息：**待核验**。
- 用户实际出行日期的天气、临时封闭和运营信息：**待核验**。

**预期行为**：
- 先询问会显著影响筛选的条件，例如日期、起点、交通方式，以及“强度适中”的距离或时长范围；必要时可先说明筛选假设。
- 使用济州偶来官方渠道等适当来源核验路线名称、状态与路线属性，并标注来源和核验时间。
- 仅在数据核实后比较海岸景观、文化主题和徒步强度；区分官方路线资料与游客个人体验。
- 若路线数据无法核实，明确说明并暂不推荐具体路线，不虚构路线编号、里程或交通连接。

**失败条件**：
- 编造路线编号、距离、难度、文化点、开放状态或交通安排。
- 把个别游客经验当成官方信息或普遍事实。
- 忽略未提供的日期、起点等约束，却声称筛选结果确定适用。

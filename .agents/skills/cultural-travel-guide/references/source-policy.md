# 来源与引用政策

## 证据等级

来源等级表示通常的证据用途，不代表某一来源对所有问题都具有同等权威。应根据主张类型判断来源是否适用，并交叉核对重要或有争议的主张。

| 等级 | 来源类型 | 适用方式与限制 |
| --- | --- | --- |
| A | 政府部门、遗产管理机构、目的地或路线运营方等官方资料 | 适合核验官方名称、管理范围、规则、开放与路线服务信息。官方叙述也可能有范围或立场限制；不自动视为学术历史结论。 |
| B | 博物馆、档案馆、研究型文化机构、专业文化组织 | 适合地点背景、藏品、建筑与地方文化说明。注明机构与具体页面或出版物；关注其专业范围及材料依据。 |
| C | 同行评审论文、学术专著、大学出版社出版物及可靠学术目录 | 适合历史解释、学术争议与深入研究。尽可能引用具体作品、作者、出版信息、页码或稳定链接；说明观点是否存在学界分歧。 |
| D | 游客经验、个人游记、论坛、评论及社交媒体 | 仅作为个人体验或近期观察的线索，不能单独证明历史事实、普遍习俗、路线安全或官方运营状态。明确标注为个人经验，并对关键内容另行核验。 |

## 引用规则

- 对可核验的事实性陈述就近引用来源；引用应足以让读者识别并查找原始材料。
- 提供机构或作者、标题、发布日期或更新时间（若有）及 URL、DOI、馆藏号或出版信息（若可得）。不确定的字段省略或标为未确认，不得猜填。
- 直接引语必须与原文一致并标明位置；不能访问原文时不要伪造引文或页码，可改为谨慎转述并注明限制。
- 解释和推论应与来源支持的事实分开，并说明推理依据；证据不足的推测明确标记。
- 对重要、争议性或可能影响出行决策的主张，优先使用多个独立且适当的来源交叉核对。来源冲突时描述分歧，不擅自消解。
- 实时或易变信息（开放时间、交通、路线状态、预约规则）优先引用对应官方渠道并注明核验时间；没有最新来源时明确提示用户再次确认。
- 游客经验不得作为官方规则或文化群体整体特征的证据。可用于描述特定作者的体验，且应注明个体性和时间范围。
- 若来源不可访问、出处不清或无法确认其可靠性，应披露限制，不以看似精确的引用掩盖不确定性。
